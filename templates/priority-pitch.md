## Final check

- [ ] Selected Track は1曲だけ
- [ ] Release Summary は500文字以内
- [ ] Spotify Artist が正しい
- [ ] Marketing Elements を1つ以上選択
- [ ] Marketing Elements は実際の予定だけ
- [ ] Past Awards / Milestones は500文字以内
- [ ] Milestones は過去・達成済みの事実だけ
- [ ] 架空の受賞、数字、プレス、広告、ツアー等を含まない
