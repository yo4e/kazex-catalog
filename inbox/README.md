# Asset Inbox

ここは KAZEX Catalog の **唯一の未整理公開素材Inbox** です。

人間はファイル名や最終分類を気にせず、公開して問題のない画像等をここへ置いて構いません。ChatGPT / Codex等のAIは `docs/ASSETS.md` と `AGENTS.md` に従い、内容と会話文脈を確認して artist / release / asset type を判定し、十分な根拠があるものだけリネーム・分類してください。

整理後の公開素材は `assets/artists/` または `assets/releases/` 以下へ移動します。

正式アー写、正式ジャケット、ロゴ等の採用状態は、山田の明示がない限りAIが勝手に確定しません。判別不能な素材はこの `inbox/` に残し、必要な場合だけ確認します。

`assets/inbox/` は使用しません。
