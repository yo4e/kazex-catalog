# KazeX Records Instagram宣伝ワークフロー

更新日: 2026-10-03

運用案。週次確認の自動実行が設定済みであることを示す文書ではない。

関連資料: [Instagram音楽宣伝の調査](INSTAGRAM_PROMOTION_RESEARCH_2026-10-03.md)

週1本程度を目安に、カタログから選曲し、静止画と動画をそれぞれ確認した後、投稿用セットをSlackへ届ける。公開は担当者がスマートフォンのInstagramアプリで行う。素材制作から投稿までを毎回やり直さず、確認とスマホ投稿に人の手間を集中する。

## 進め方

1. **週次チェック**。進行中の1本があればその続きだけを案内する。確認待ちに新しい制作物を積み増さない。何も進行していなければ推奨1曲と短い選定理由を用意し、担当者が都合のよいときに開始できる状態にする。
2. **選曲と音源確認**。公開カタログを読み、正式artist名、曲名、収録作品、配信状況、曲へのリンク、公開済み素材を照合する。許可された原本フォルダでWAVを特定し、同名別曲・別mix・未完成版を避ける。ファイル名だけで確定せず、尺と試聴でも一致を確かめる。
3. **静止画制作と承認1**。推奨曲、宣伝する理由、画像、動画で使う区間案を一緒に提示する。確認対象は曲と版、世界観、人物や構図、画面内文字。承認された画像を動画制作の基準にする。
4. **動画制作と承認2**。音入り確認動画、表紙、caption、聴く先への導線をまとめて提示する。確認対象は冒頭の引き、動き、音との同期、文字の読みやすさ、終端、公開する文章。承認後に映像や文章を大きく変えた場合は再確認する。
5. **Slack納品**。同じ投稿のスレッドに最新の承認版一式をまとめる。captionは説明を混ぜず、コピーしやすい独立メッセージにする。動画はリンクだけでなく、スマホで保存できるファイルとして届ける。
6. **スマホ投稿**。担当者が投稿用動画を保存し、Instagram公式音源を選び、指定区間に合わせ、captionを貼って公開する。最後に公開URLを返す。
7. **公開確認と振り返り**。公開URL、曲名表示、音の有無、caption、誘導先を確認する。取得可能な数値で24時間後と7日後を比較し、次の1本に反映する。閲覧権限がない数値は空欄のままにする。

## 選曲の判断材料

推奨は売上予測ではなく、手元の根拠に基づく制作優先順位とする。

- いま聴かせる理由があるか。新作、作品のテーマ、季節、既存投稿への反応など、確認できる根拠を使う。
- 最初の短い区間で特徴が伝わるか。曲名や制作プロンプトだけで決めず、実際の音源を聴く。
- 正しいマスターと公開素材がそろっているか。
- 最近の投稿と同じ曲・同じ見せ方が続いていないか。
- 実績を見られる場合は、再生数だけでなく保存、シェア、実際に聴く先へ進んだ反応も参考にする。

カタログが古い場合は配信ページを優先して確認する。日付を過ぎた `upcoming` をそのまま発売前と読まない。Spotify URL、再生数、ISRC、NASの所在は推測しない。

## 1投稿の納品セット

- **投稿用動画**: 原則9:16、1080×1920のMP4。8秒ループを出発点とし、聴かせたい区間に必要なら尺を調整する。これは運用上の標準でありプラットフォームの上限を示すものではない。
- **音入り確認動画**: WAVの承認区間を重ねた試聴用。ファイル名と説明に「確認用」を入れる。
- **表紙画像**: 最初のフレームまたは承認された静止画。曲名等は実際の投稿プレビューで切れない位置に置く。
- **caption**: 採用案1本。冒頭の一文、正式artist名・曲名、聴く先への行動案内、必要な表記、関連タグ少数。
- **投稿メモ**: 公式音源の検索語、選ぶartist・曲名、音の開始目印と区間、Spotify曲URL、必要ならStory用短文。
- **版情報**: 投稿単位の識別子と版番号。修正版が出たらどれが最終版かを明示する。

## 公式音源と音入り動画

公式音源を使う場合は、無音の投稿用動画と音入り確認動画を分ける。スマホでは正式な曲とartistを確認してInstagram側の音源を付ける。開始秒数は公式音源の収録区間とWAVで一致しないことがあるため、秒数だけでなく聴こえる目印を添える。

音入り確認動画をそのまま投稿し公式音源も加えると二重再生になり得る。元動画音量を0にするか、無音版を使用する。公式音源が見つからない場合は、誤った曲を代用せず停止する。権利と投稿目的を確認した自前音源入り版を使う案もあるが、それだけで公式曲ページに紐付くとは限らない。

Metaは、一部のbusiness account、投稿種別、国・地域で音楽ライブラリの利用が制限されると説明している。PCとスマホ、アカウント、地域で表示が違う可能性があるため、実際の投稿画面を最終確認とする。公式音源利用を前提に有料広告へ流用しない。[Metaの音楽ライブラリ説明](https://www.facebook.com/help/instagram/402084904469945)

## 聴く先への導線

動画とcaptionで興味を持った人が、迷わず対象曲を開けるようにする。captionに書く案内は実在し、投稿時に利用できる導線だけにする。

- プロフィールのリンクが対象曲へ到達することを確認できた場合は「フルはプロフィールのリンクから」。未確認ならこの文言を使わない。
- 小さな追加作業として、スマホのSpotifyから曲をInstagram Storiesへ共有する方法がある。2025年8月のSpotify公式案内では、音声プレビューを含み、曲ステッカーからSpotifyへ進める。[Spotify公式案内](https://newsroom.spotify.com/2025-08-21/spotify-takes-instagram-sharing-to-the-next-level-with-audio-previews-and-real-time-listening-notes/)
- Storyに直接曲のリンクスタンプを置く方法もある。表示・利用可能性は投稿時のアカウントで確認する。[Metaのリンクスタンプ説明](https://about.fb.com/ja/news/2021/10/linkaccessstickers/)
- 新たなアカウント連携、プロフィール変更、公開投稿は別途その操作への承認範囲を確認する。

## 測定

1. 投稿前: 対象曲の直前7日間のSpotify listeners・streams・savesを、既にアクセスできる場合に記録する。
2. 24時間後: Instagramのリーチ、再生、平均視聴時間、保存、シェア、プロフィールへの反応を、画面で取得できる範囲で記録する。8秒動画の平均視聴時間は繰り返し再生の影響を受け得るため、完視聴率と同一視しない。
3. 7日後: 同じInstagram数値と対象曲のSpotify数値を確認する。既存の計測リンクやStoryのリンクタップ数を取得できるなら別項目にする。新しい計測サービスや設定を無断で導入しない。
4. 次回: 動画冒頭、曲区間、captionのCTAなど一度に大きく変える要素を絞る。異なる週の比較は厳密なランダム化実験ではなく、改善の手がかりとして扱う。

Instagram再生、リンククリック、Spotify再生は別の数値である。SpotifyのSource of streamsはSpotify内の再生元分類であり、個別のInstagram投稿から何再生生まれたかを直接示さない。投稿後に再生が増えても投稿単独の因果効果と断定しない。

Spotifyの通常統計は日次更新、日付はUTC基準。Instagram側の記録日時も併記する。数値が見られない場合は担当者からスクリーンショットを受け取るだけでもよい。[Spotify統計更新](https://support.spotify.com/de-en/artists/article/when-stats-update/) / [再生元の定義](https://support.spotify.com/dk-en/artists/article/source-of-streams/) / [Metaの視聴時間説明](https://about.fb.com/news/2023/04/instagram-reels-trending-audio-and-gifts-updates/)

## 公開カタログに置く情報

公開可能な手順、調査根拠、正式な作品情報、承認済み公開素材、公開投稿URLを扱う。個人ストレージのパス、認証情報、非公開Slack会話、個別の非公開統計は公開リポジトリに含めない。原本の所在や制作途中の管理情報は別の非公開管理先で扱う。
